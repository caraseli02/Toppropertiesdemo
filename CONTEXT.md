# TopProperties Context

## Glossary

### Luxury property discovery demo

A polished portfolio/demo release for discovering luxury homes through the current visual browsing experience. It should help a buyer explore curated homes, scan destinations or regions, and open supporting listing and property detail views.

This does **not** mean building a deep production marketplace backend, broad agent platform, or account-based product. The release should stay mostly visual/product-led and close to the current UI.

V1 exclusions: booking/contact workflows, mortgage/financing calculators, user accounts/saved searches, real CRM, and real listing ingestion. The demo should spend complexity on polish, coherence, and basic browsing flows, not production marketplace plumbing.

_Avoid_: agentic-native property webapp, Mallorca-only app, production marketplace

### Luxury discovery moment

The primary demo moment helps a buyer discover appealing luxury home options through the existing browsing UI. It may use curated sections, destination cards, listings, filters, or property detail views, but the release is not defined by agentic-native technology.

The v1 demo scope follows the current UI direction rather than being restricted to Mallorca-only inventory.

Primary user/persona: a luxury buyer or investor browsing premium homes and destinations. This persona justifies premium editorial UI, curated inventory, and confident visual presentation.

Primary theme for v1: polished browsing and property discovery. Calendar or messaging handoff can be secondary/future, not the core v1 concern.

Visual direction should stay premium, editorial, and discovery-led. Current guardrail: the experience should not drift into a technical AI dashboard.

_Avoid_: hero agentic moment, AI dashboard, static filter result list

### Three-page discovery shell

The MVP release shape: a Home page for discovery, a Listings page for browsing curated residences, and a Property Detail page for supporting depth on a selected home. It is a portfolio/demo structure, not a full marketplace information architecture.

_Avoid_: broad marketplace app, destination portal, account-based product

### MVP release bar

The minimum release standard for the current demo: the three-page discovery shell is coherent, verified, and deployable. Home, Listings, and Property Detail should work together with internally consistent copy/data, acceptable mobile behavior, and passing project verification.

_Avoid_: redesign mandate, architecture spike, production readiness
