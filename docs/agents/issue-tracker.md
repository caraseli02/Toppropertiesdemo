# Issue Tracker

Toppropertiesdemo uses GitHub Issues as the issue tracker.

- Repository: `caraseli02/Toppropertiesdemo`
- CLI: `gh`
- PRDs from Matt Pocock skills should be published as GitHub Issues.
- Vertical-slice implementation work from `to-issues` should be published as GitHub Issues.
- Apply the `ready-for-agent` label when a ticket is fully specified and can be picked up by an AFK agent.

## Rules for agents

- Read the full issue body and comments before planning work.
- Do not close or modify parent issues unless explicitly instructed.
- For implementation work, create a branch from latest `main`, push, and open a PR.
- Use Kanban for execution tracking even when GitHub Issues is the source of product/implementation tickets.
