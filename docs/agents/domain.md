# Domain docs: single-context

This repository uses a single-context layout.

## Layout

- `CONTEXT.md` at the repository root contains the active context for agents.
- `docs/adr/` contains architecture decision records.

## Conventions

- Keep root context concise and current.
- Add new durable decisions to `docs/adr/` as individual ADR files.
- Prefer one source of truth in `CONTEXT.md` for active repo context.
